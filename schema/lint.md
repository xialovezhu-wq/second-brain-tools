# lint 工作流

创建日期：2026-06-28

## 目标

lint 用于定期体检第二大脑 LLM Wiki，检查孤立页面、矛盾结论、过期信息、缺少链接、未处理 raw source、index/log 不一致和边界违规。

lint 默认只读，只输出报告；用户明确要求修复时，才在 wiki / schema 派生层做小范围修改。raw source 和专项正式数据仍不得自动改写。

## 预读顺序

1. `AGENTS.md`
2. `第二大脑/00-运行规则.md`
3. `第二大脑/schema/00-LLM-Wiki运行规则.md`
4. 本文件
5. `第二大脑/wiki/index.md`
6. `第二大脑/wiki/log.md`
7. 需要检查的目标目录或文件

## 检查项目

| 项目 | 检查内容 | 输出 |
| --- | --- | --- |
| 孤立页面 | 页面是否没有被 `wiki/index.md`、节点、关系、复盘或索引链接 | 文件路径、建议链接入口 |
| 矛盾结论 | 每日记录、长期状态记录、节点、关系之间是否有日期、时长、结论冲突 | 冲突位置、证据、建议处理 |
| 过期信息 | `最后更新` 过旧、待确认问题长期未闭合、等待回填的结论未处理 | 文件路径、过期类型 |
| 缺少链接 | 节点/关系页面是否缺少相关主题互链 | 建议链接对象 |
| 关系卡健康 | 必填属性、来源链接、反例、共同变量、状态和复核日期是否齐全 | 缺失字段、过期卡、建议降级或复核 |
| 未处理 raw source | 原始对话、每日记录、学习过程摘要、同步包是否未进入 index/log | 来源文件、建议动作 |
| index/log 一致性 | `wiki/index.md` 最近更新是否能在 `wiki/log.md` 找到记录 | 缺失项 |
| 边界违规 | 专项完整题干解析是否误入第二大脑，敏感内容是否超过中性记录边界 | 风险说明、建议回退方式 |
| 结构校验 | 每日日期连续性、表格列数、JSON、Base YAML、链接歧义和缓存新鲜度 | P1/P2/P3 检查结果 |

## 本地只读检查

优先运行：

```bash
python3 第二大脑/scripts/second_brain_lint.py
```

需要机器可读结果时使用：

```bash
python3 第二大脑/scripts/second_brain_lint.py --json
```

脚本只读，不自动修复；P1 返回非零，P2/P3 默认只报告。Obsidian 打开时仍应配合 CLI 检查 backlinks、tags 和解析状态。

## 严重程度

| 等级 | 含义 | 处理 |
| --- | --- | --- |
| P0 | 可能破坏隐私、安全、专项边界或关键数据结构 | 必须先报告，不能自动修复 |
| P1 | 明显矛盾、重要结论过期、日志缺失 | 建议优先修复 |
| P2 | 链接缺失、索引不完整、待确认项可清理 | 可批量计划，但不默认批量执行 |
| P3 | 文案、格式、导航体验问题 | 低优先级 |

## 日志规则

lint 完成后，如果没有修改文件，可在回复中说明“只读 lint，未写入日志”。如果用户要求保存 lint 报告或执行修复，必须在 `wiki/log.md` 追加对应记录。
