# 第二大脑结构与检查工具

面向本地 Markdown 知识库的结构维护工具，提供入库、查询、检查等流程约定和库健康检查脚本。真实每日记录、健康信息、个人画像、对话和附件均不公开。

## 目录

- `scripts/second_brain_lint.py`：检查节点、关系与索引结构。
- `scripts/test_second_brain_lint.py`：现有脚本检查。
- `schema/`：入库、查询与检查的规则。

```sh
python3 scripts/second_brain_lint.py --help
```

运行前需要建立自己的知识库，并根据脚本参数指定其路径。公开源码不等于已经包含可查询的个人知识库。

## 公开范围

这是从本机工作源码整理的公开副本。只包含代码、运行逻辑和必要结构，不包含真实学习记录、完整对话、学习画像、健康记录、原始教材、凭据、浏览器数据或运行数据库。路径中的 `YOUR_USER` 必须按本机环境配置。源码检查不代表已在另一台电脑部署成功；本次发布不启动服务、不写入真实学习库。
